Week 12 Overview
This week, we will discuss how differences-in-differences (DID) can be used to estimate causal effects by comparing changes over time between treated and untreated groups. We will explore the assumptions underlying DID—particularly the parallel trends assumption—and examine how to evaluate those assumptions using graphical diagnostics, placebo tests, and regression techniques. We will also implement DID using two-way fixed effects models, interpret treatment effects across multiple time periods, and understand how to handle more complex designs, such as staggered treatment rollouts. Finally, we will compare DID to event study approaches and consider strategies like matching to strengthen causal claims. 


Learning Objectives 
At the end of this week, you will be able to: 

Apply differences-in-differences to data. 
Understand and test the parallel trends assumption. 
Review some regression topics from Week 7.
