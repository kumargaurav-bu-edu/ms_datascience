# Bayes' Rule, Naïve Bayes, and Evidence Lift Quiz

## Overview

This comprehensive quiz covers the key learning objectives for DX699:
- **Bayes' Rule**: Understanding conditional probability and Bayesian updating
- **Naïve Bayes**: Learning about the Naïve Bayes classifier and its assumptions
- **Evidence Lift**: Understanding how evidence affects probability beliefs

## Files

- `bayes_quiz.json` - Quiz questions in JSON format (30 questions)
- `bayes_quiz.py` - Interactive Python quiz program
- `README.md` - This file

## Usage

### Running the Quiz

From the `dx-699` directory, run:

```bash
python3 bayes_quiz.py
```

### Quiz Features

1. **Difficulty Levels**: 
   - Basic (13 questions): Definitions and conceptual clarity
   - Intermediate (11 questions): Formula application and interpretation
   - Advanced (6 questions): Complex scenario analysis and model comparison

2. **Question Types**:
   - Multiple choice
   - True/False
   - Fill-in-the-blank
   - Scenario-based reasoning
   - Formula application

3. **Topics Covered**:
   - **Bayes' Rule** (13 questions): Prior/posterior probabilities, likelihood, evidence, real-world applications
   - **Naïve Bayes** (10 questions): Independence assumption, text classification, Laplace smoothing, computational advantages
   - **Evidence Lift** (7 questions): Lift calculation, interpretation, combining evidence, practical applications

4. **Real-World Context**:
   - Fraud detection
   - Credit scoring
   - Customer churn
   - Marketing response models
   - Medical diagnosis
