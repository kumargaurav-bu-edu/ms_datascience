For all HW reflections submissions, you will be required to submit two separate files:



(1) a single Jupyter notebook compiling all the code used to answer the questions for those weeks, and

(2) a PDF document presenting your written responses, which should include selected portions of your code relevant to the answers.



You only need to mandatorily write code for questions where it specifically asks for code. Rest of the questions, code is not required but if you have done any analysis or used code to write your answer, it's recommended to attach the code snippets in the PDF files.



Naming conventions : LastName_FirstName_reflectionnumber.pdf (example Smith_John_reflection1.pdf)

LastName_FirstName_reflectionnumber.ipynb (example Smith_John_reflection1_notebook.ipynb)



Expect us to primarily read your PDF files to grade your submissions, therefore it is required to attach code snippets as images in the PDF submissions.

The Notebook Submissions should still contain all code (if any) used to answer the reflection questions.



Please keep your submissions clean and easy to read. Format for PDF files should be :

(Week Number)

Question 1 (written answers with code snippets)

Question 2 (written answers with code snippets)
